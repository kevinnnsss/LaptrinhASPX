Giao Diện Khách Hàng (Front-end)

  • Trang chủ Default.aspx: Banner, đồng hồ mới nhất, thương hiệu Casio, Seiko, Citizen, Rolex.
  • Menu đa cấp tự động đọc từ CSDL (bảng Menus).
  • Bộ lọc thông minh ProductList.aspx theo hãng và giới tính.
  • Chi tiết đồng hồ ProductDetail.aspx: Ảnh lớn, tồn kho, bảo hành Red Guarantee.
  • Trang tin tức & cẩm nang cỗ máy cơ: NewsList.aspx, NewsDetail.aspx.
🛡️

Phân Hệ Quản Trị Hệ Thống (Admin)

  • Giao diện Quản trị riêng biệt: Admin/Admin.Master & admin.css.
  • Bảo mật kiểm tra quyền đăng nhập: Chặn khách vào trực tiếp trang quản trị bằng Session.
  • Dashboard.aspx: Thống kê số lượng đồng hồ, danh mục, đơn hàng, người dùng.
  • ManageProducts.aspx: Thêm, sửa, xóa, tìm kiếm đồng hồ + Upload ảnh bằng FileUpload.
  • ManageOrders.aspx: Xem và duyệt 5 trạng thái đơn hàng (Chờ xử lý, Đã xác nhận, Đang giao, Đã hoàn tất, Đã hủy).
  • ManageAccounts.aspx: Quản lý tài khoản, phân quyền và khóa truy cập.
🛒

Bán Hàng & Tra Cứu Đơn Hàng

  • Giỏ hàng lưu trữ linh hoạt bằng phiên làm việc Session["Cart"].
  • Đặt hàng an toàn: Kiểm tra tồn kho thời gian thực, lưu đơn hàng và chi tiết đơn hàng trong một Giao dịch (Transaction) an toàn.
  • Trang thông báo đặt hàng thành công: OrderSuccess.aspx.
  • Tra cứu tiến độ đơn hàng: TrackOrder.aspx tra cứu bằng SĐT hoặc Mã đơn với thanh Stepper Timeline 4 bước trực quan.
  • Đăng ký thành viên: Register.aspx cho khách hàng tạo tài khoản, tự động gán quyền Permission = 2, mật khẩu băm SHA-256.
⚡

Tối Ưu Trải Nghiệm & ASP.NET AJAX

  • ASP.NET AJAX UpdatePanel: Tăng/giảm (+/-) số lượng đồng hồ không giật lag màn hình.
  • Đồng bộ tức thời giỏ hàng Header (Live Sync) với UpdateCartPreview().
  • Hiệu ứng Spinner UpdateProgress với lớp phủ mờ khi hệ thống tính toán dữ liệu.
  • Áp dụng mã giảm giá Voucher 10% (KEV10, CHAOBAN) tức thì trong giỏ.
  • Kiểm tra dữ liệu đa tầng: RequiredFieldValidator, RegularExpressionValidator (SĐT 10 số, Email), CompareValidator.
  • Phương thức thanh toán linh hoạt: COD và Chuyển khoản ngân hàng VietQR.
🗄️

Cơ Sở Dữ Liệu SQL Server 2022

  • CSDL có tên layout với 6 bảng chuẩn hóa: Acounts, Menus, PageItems, ProductPrices, Orders, OrderDetails.
  • Mô hình quan hệ 1-Nhiều và 1-1 chặt chẽ với khóa ngoại (Foreign Key).
  • File ánh xạ đối tượng ORM chuẩn: WatchStore.dbml.
  • Lớp trợ giúp truy cập CSDL dùng chung: DbContextHelper.cs.
🔒

Bảo Mật & Độ Tin Cậy Cao

  • Băm mật khẩu 1 chiều chuẩn quốc tế SHA-256 thông qua SecurityHelper.HashPassword().
  • Chống tấn công SQL Injection: LINQ to SQL tự động tham số hóa 100% truy vấn.
  • Chống tấn công XSS: Mã hóa an toàn mọi dữ liệu người dùng nhập bằng Server.HtmlEncode().
  • Hệ thống biên dịch không lỗi (0 Warnings, 0 Errors trên MSBuild).

🚀 Hướng Dẫn Cài Đặt & Chạy Website Trên Máy Cục Bộ (IIS / Visual Studio)

Để chạy website hoàn chỉnh có kết nối cơ sở dữ liệu và xử lý nghiệp vụ bán hàng, làm theo 4 bước sau:

Bước 1: Nạp Cơ Sở Dữ Liệu

Mở SQL Server Management Studio (SSMS) → Mở file Database_layout.sql ở thư mục gốc → Nhấn Execute (F5) để tạo database layout và dữ liệu mẫu.

Bước 2: Mở Dự Án

Khởi động Visual Studio 2022 → Chọn Open a project or solution → Trỏ tới file BCBTL.slnx hoặc BCBTL/BCBTL.csproj.

Bước 3: Cấu Hình Kế Nối

Kiểm tra file Web.config: Đảm bảo chuỗi kết nối layoutConnectionString trỏ đúng vào SQL Server local của máy bạn (mặc định: localhost).

Bước 4: Khởi Chạy Website

Đặt file Default.aspx làm Set As Start Page → Nhấn Ctrl + F5 để chạy trên IIS Express hoặc Publish ra IIS cục bộ.
